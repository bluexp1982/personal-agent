# 账单解读

把一笔看不懂的账单拆开：费用构成 → 异常项 → 能做什么。

## 步骤说明

1. **读取账单内容**：从输入 `text` 取账单正文；为空时说明缺少材料。
2. **归纳费用构成**：按类目归并，标出占比最大项与明显异常（如有）。
3. **给出可执行建议**：最多 3 条，例如"取消自动续费""核对某日消费"。

## 产物

- `summary`：费用构成与建议的文本摘要。

## 边界

- 只做解读，不做争议处理，不代为联系客服。
- 不臆测金额：材料里没有的数字一律不写。
